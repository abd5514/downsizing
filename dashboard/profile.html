Account

Changes here last until the server restarts. To keep them for good, also set DROWSIM_ADMIN_NAME and DROWSIM_ADMIN_EMAIL on Render.

Password

The password is kept on Render, so it survives restarts. Changing it signs everyone out, and the laptop client needs the new one too.

  1. Open dashboard.render.com and choose the drowsim service.
  2. Go to Environment and edit DROWSIM_PASSWORD.
  3. Click Save. Render redeploys in a few minutes.
  4. Sign in again here with the new password.
